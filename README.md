Smart Bazaar — Grocery Sales Analysis

A data analytics project focused on exploring grocery sales data and turning raw records into useful business insights using Excel, SQL, and Power BI.

The dataset contains more than 7,000 sales records, which can be cleaned, queried, analyzed, and visualized to understand customer purchasing patterns and overall sales performance.

📌 Project Overview

The goal of this project is to examine grocery sales data from different perspectives and present the findings in an easy-to-understand way.

The project combines:

Excel for organizing and working with the raw data

SQL for querying the dataset and extracting specific information

Power BI for creating interactive dashboards and visual reports

🛠️ Tools & Requirements

To work with this project, you will need:

Microsoft Excel

SQL Server or another SQL-compatible database

Power BI Desktop

A Windows, macOS, or Linux computer

Using recent versions of these applications is recommended for smoother compatibility.

📂 Project Workflow

1. Prepare the Data

Open the Excel data file and review the available sales records. Excel can be used for basic data handling and preparation before moving the data into SQL or Power BI.

2. Analyze with SQL

Load the dataset into SQL Server or another compatible database system.

The SQL scripts included in the project can be used to:

Filter and organize sales records

Extract relevant business information

Analyze sales performance

Identify patterns within the dataset

3. Build Visualizations in Power BI

Import the dataset into Power BI Desktop and use the available fields to create charts, tables, and interactive dashboards.

The dashboard can be used to explore sales performance from different dimensions.

📊 Key Analysis Areas

The project can be used to investigate areas such as:

Sales performance across different periods

Products with higher customer demand

Regional differences in sales

Changes in purchasing behavior over time

Seasonal sales patterns

These observations can help in understanding customer demand and identifying areas that may require further business analysis.
